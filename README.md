# Gluten Free Finder

Piattaforma collaborativa per celiaci.

## Funzionalità

- Ricerca locali gluten free
- Ricerca negozi specializzati
- Recensioni utenti
- Valutazioni a stelle
- Mappa interattiva
- Upload foto
- Gestione preferiti

## Tecnologie

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- OpenStreetMap

## Avvio progetto

```bash
npm install
npm run dev
